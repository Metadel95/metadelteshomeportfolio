# Portfolio

Static site. No build step.

## Add your work
1. Make a folder: `images/projects/my-project/`
2. Drop in `cover.jpg` plus your other images (`1.jpg`, `2.jpg`, ...)
3. Open `index.html` and find the `SITE` block at the top of the script (marked EDIT ONLY THIS), copy a block in `projects: [...]`, change the title, category and image paths.
4. Commit and push. Vercel redeploys automatically.

You can also upload images straight on GitHub: open the folder, click **Add file > Upload files**.

Your photo goes in `images/profile.jpg`. All text lives in the `SITE` block in `index.html`.

## Deploy
Push to GitHub, then on vercel.com choose **Add New > Project**, import the repo, and click Deploy. Framework preset: **Other**.
